# proyecto-agebre
💻 Plataforma AGEBRE UGEL 05 - Sistema MOPED Este proyecto busca centralizar la información, el repositorio de documentos y el monitoreo pedagógico (MOPED) de la UGEL 05, permitiendo a los especialistas registrar datos de campo y generar reportes dinámicos.

🚀 Estructura del Proyecto El proyecto está diseñado con un enfoque modular y se basa en las siguientes funcionalidades principales:

Módulo Informativo/Público: Página de inicio y repositorio de documentos.

Módulo de Monitoreo (MOPED): Acceso privado para especialistas para registro de fichas y visualización de progreso.

Módulo de Reportes: Dashboard administrativo con gráficos dinámicos y datos consolidados para la jefatura.
